CoCo Canonical Documentation

HealthLX canonical data models for CMS compliance and FHIR interoperability.

Implementation Guides

  • Core-Model Implementation Guide Core shared types and base elements used across all canonical models.
  • EOB Implementation Guide Explanation of Benefits canonical model for CMS-9115 compliance.
  • Clinical Implementation Guide Clinical data canonical model for patient access and interoperability.
  • Formulary Implementation Guide Drug formulary canonical model aligned with CMS drug coverage requirements.
  • Provider Directory Implementation Guide Provider directory canonical model for the Provider Directory API.
  • Roster Implementation Guide Member roster canonical model for payer-to-payer data exchange.

About CoCo

CoCo provides a canonical, open, and inspectable representation of CMS compliance intent that can be consistently implemented across heterogeneous payer systems and downstream FHIR platforms. All canonical artifacts are versioned and traceable to regulatory source material.

Steered by HealthLX and the open-source community. Contributions and pull requests are welcome — see the GitHub repository.
